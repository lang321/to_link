# 一键部署包 · REQ-REMOTE-20261105-05

## 需求 · REQ-REMOTE-20261105-05

Linux 解压后运行 install.sh 即可部署并启动服务，支持开机自启动；更新保留设备数据与注册密钥。

## 详细设计 · REQ-REMOTE-20261105-05

包内提供 x86_64、ARM64 的独立 Node.js 24 运行环境及应用依赖，无需下载或修改系统 Node。程序采用 releases/current 布局；配置、状态分别保存在 /etc/tolink、/var/lib/tolink。安装加锁，校验包文件、配置、端口；启用服务后检查 /health。失败时恢复旧链接、配置和 service 文件，不回写或清空设备状态。

## 代码开发 · REQ-REMOTE-20261105-05

入口 deploy/install.sh；管理 deploy/manage.sh；配置/健康检查 deploy/tools；打包 ops/package-server.py。支持 --port、--bind、--public-url 和隔离 --instance。默认 HTTP/WS，公网 HTTPS 由外部反向代理提供，脚本不修改防火墙或申请证书。

## 代码审核 · REQ-REMOTE-20261105-05

核对了架构识别、运行环境 SHA256、配置权限、端口归属、失败恢复、配置数据保留、实例名称限制、无 eval、无全局 Node 替换。包中不包含当前测试服务器的注册密钥或设备身份。系统账户 tolink 专用于服务；应用代码只读，设备目录可写。

## 测试 · REQ-REMOTE-20261105-05

已在 Ubuntu 24.04 ARM64 / systemd 上完成：

配置生成器的 3 项自动化测试通过；Bash 和 JavaScript 语法检查通过。x86_64 运行文件已按官方下载校验和及 ELF 架构验证，未进行 x86_64 实机安装测试。未对无 systemd、Alpine/musl 或未提供的公网 HTTPS 环境验收。
