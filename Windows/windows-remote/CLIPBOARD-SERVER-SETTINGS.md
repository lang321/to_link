## 详细设计 · REQ-REMOTE-20261105-02 / REQ-REMOTE-20261105-03

粘贴使用浏览器原生 paste 事件，仅在已启用控制且画面获得焦点时读取 text/plain，复用原有 text → SendInput Unicode 通道。修饰键延迟到组合确定后转发，避免 ⌘V 被误发为远程 Win+V。不轮询剪贴板，不同步 Windows 剪贴板，不传文件、图片或富文本格式。单次上限保持 1000 个 UTF-16 单元；超限提示并拒绝，不截断发送。

服务器地址支持 IP:端口、http/https/ws/wss；统一保存为 ws/wss 根地址，拒绝账号、路径、查询参数和片段。配置中的 Servers 字典按规范化地址保存 ID、设备令牌、密码和待注册信息。切换先停止旧连接，再保存配置并连接；新地址使用独立身份，切回原地址恢复原身份。不同别名地址视作不同配置，避免把原服务器凭据发送给另一服务器。

未注册的新客户端先确认地址再点“保存并连接”。首次连接新服务器需该服务的注册密钥；仅内置的测试服务器地址可自动使用安装包中的注册凭据。已经保存的设备身份不需要重复填写注册密钥。
