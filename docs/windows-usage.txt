ToLink 单文件版 · REQ-REMOTE-20261105-01

只需复制 ToLink.exe 到 Windows，双击启动。
首次运行会自动释放编码器和初始配置到 %LOCALAPPDATA%\ToLink。
设备 ID、密码配置和日志保存在该目录，后续更新不会覆盖已有配置。
新设备首次启动自动分配 ID；不再需要手动携带 ffmpeg.exe 或 agent.json。
从旧便携版升级时，把单文件 EXE 放在旧 agent.json 同目录运行，可在首次启动时迁移配置。
本包使用现有测试服务器，仅供内部测试。

文件：先选中远程目标文件夹，再在画面上粘贴，或点击“粘贴文件”多选。每批最多 32 个文件、总计 100 MiB。

锁屏／息屏唤醒 · REQ-REMOTE-20261110-01
首次需要同时携带 ToLink.DesktopHost.exe、install-lock-support.ps1 和“安装锁屏支持.cmd”。
双击“安装锁屏支持.cmd”，用运行 ToLink 的同一 Windows 账号接受管理员授权。
之后正常运行 ToLink.exe，在浏览器点击“唤醒屏幕”，再启用控制、输入系统密码。
锁屏界面请直接键入密码，不支持剪贴板粘贴。系统睡眠、休眠和关机不在本次范围。
测试账号无密码；带密码账号和强制 Ctrl+Alt+Del 登录策略尚未验收。

云桌面式文件粘贴 · REQ-REMOTE-20261111-01
新版服务器 + 本版 Windows 客户端支持边传输边粘贴：先选中远端目标文件夹，再在浏览器粘贴或通过“粘贴文件”选择。
粘贴开始后使用 Windows 自带的“正在复制”窗口显示进度、处理重名和取消，不必等整批传完才开始复制。
请保持浏览器连接；浏览器拿不到本机剪贴板文件内容时，仍需通过“粘贴文件”选择。
