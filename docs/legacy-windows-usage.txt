ToLink 单文件版
需求：REQ-REMOTE-20261105-01 / 02 / 03

退出旧版后，复制并双击 ToLink.exe。
首次运行会自动释放编码器到 %LOCALAPPDATA%\ToLink，无需另带 ffmpeg.exe。
在客户端填写服务器地址，例如 192.168.100.101:19000，点击“保存并连接”。
首次连接其他服务器需要该服务器的注册密钥；当前内置测试服务器可留空。
每个服务器地址分别保存设备 ID 和密码，切回原地址会恢复。
浏览器输入设备 ID 和密码连接，启用控制并点击远程输入框后，按 ⌘V / Ctrl+V 可粘贴外部纯文本。
单次最多 1000 字符，超限提示而不截断；不支持图片和文件粘贴。
